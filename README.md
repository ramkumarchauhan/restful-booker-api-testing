# Restful-Booker API Testing

## Project Overview
This project focuses on manual REST API testing of the Restful-Booker hotel booking API using Postman.

## Tools
- Postman
- REST API
- JSON
- HTTP methods and status codes
- Excel-based test documentation

## API Base URL
https://restful-booker.herokuapp.com

## Scope
- Authentication
- Create booking
- Retrieve booking IDs
- Retrieve booking details
- Update booking
- Partial update booking
- Delete booking
- Positive and negative testing
- Request and response validation
- Basic Postman test scripts
- Defect reporting and test summary

## Project Structure
- `Postman/`: Postman collection and environment
- `Test-Documentation/`: Test plan, test cases, execution report, defect report, RTM, and summary report
- `Evidence/`: Screenshots and defect evidence

## Execution Flow
1. Import the Postman collection and environment.
2. Generate an authentication token.
3. Create a booking.
4. Retrieve and validate booking details.
5. Update or partially update the booking.
6. Delete the booking.
7. Record execution results and defects.
8. Update the RTM and test summary report.
